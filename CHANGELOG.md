# MoreCodex changelog

## 0.1.0-preview — 2026-09-22

Initial MoreCodex source preview, based on codex-chatgpt-web v5.0.6.

- Import independent Web/HTTP account configuration and account-bound model catalogue support.
- Import model/workspace verification, configurable selectors and browser-session ownership handling.
- Import Windows route guards, runtime validation, reversible integration and startup helpers.
- Add MoreCodex branding, separate default bridge/launcher directories, a distinct installer identity and repository-specific update endpoints.
- Publish English/Chinese documentation, focused preview CI, known limitations and upstream attribution.

The preview includes experimental paths. No binary installer or all-account, all-platform acceptance claim is included. See [preview status](docs/preview-status.md).

Earlier history belongs to the original project; see [UPSTREAM.md](UPSTREAM.md).
